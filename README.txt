でんしゃ放送 PWA（音声ファイル対応版）

主な機能
- 子ども用の大きな3ボタン
- ボタン1/2/3それぞれに音声を登録可能
- 親設定から「その場で録音」または「音声ファイルを選ぶ」を選択可能
- MP3 / M4A / WAV / AAC など、iPhoneで再生できる一般的な音声形式に対応
- ボタン3は音声未登録なら標準ベル音を再生
- おとな設定は歯車を2秒長押し
- 初期暗証番号: 2580
- ボタン名を変更可能
- 音声はiPhone側のIndexedDBに保存
- Service Workerによるオフライン動作

使い方
1. 親設定を開く（歯車を2秒長押し → 初期暗証番号2580）
2. 各ボタンで「その場で録音」または「音声ファイルを選ぶ」を選択
3. 「試しに再生」で確認
4. 設定を閉じれば、子ども用の大ボタンから再生できます

音声ファイルについて
- iPhoneの「ファイル」アプリ等から選択できます。
- Apple Musicの曲を直接選ぶ機能ではありません。使いたい音声をファイルとしてiPhoneに保存してください。
- 50MB以下を目安にしてください。

注意
- マイク録音にはHTTPSが必要です。GitHub PagesなどHTTPSで配信してください。
- GitHub Pagesのリポジトリに録音・選択した音声データはアップロードされません。
- iPhoneのWebサイトデータ/PWAデータを削除すると登録音声が消える可能性があります。
